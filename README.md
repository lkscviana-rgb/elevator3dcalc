# ELEVATOR3DCALC

Calculadora estática de custos e preço de venda de peças impressas em 3D. Não precisa de servidor nem banco de dados: basta publicar `index.html` em um serviço de páginas estáticas.

## Publicar pelo GitHub Pages

1. Crie um repositório público no GitHub, por exemplo `elevator3dcalc`.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`, e salve.
5. Aguarde a publicação. O GitHub mostrará o endereço público em **Settings → Pages**, normalmente no formato `https://SEU-USUARIO.github.io/elevator3dcalc/`.

## Atualizar depois

Edite o `index.html` e envie a nova versão para a mesma branch. O endereço do site continua igual; pode levar alguns minutos para a atualização aparecer.

## Privacidade

Impressoras cadastradas e valores salvos ficam no armazenamento local do navegador de cada dispositivo. Eles não são sincronizados entre dispositivos nem enviados ao repositório. O código-fonte do site fica público quando o repositório é público.
